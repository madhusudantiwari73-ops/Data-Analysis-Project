## Project Objective

The objective of this project was to provide a clear visualization of business performance and make key insights easier to understand.

## Approach

1. **Data Preparation:** Collected and cleaned the required data using SQL and standard joins.
2. **Data Analysis:** Used Excel Pivot Tables and Pivot Charts to perform and present structured analysis.
3. **Visualization:** Developed a BI dashboard to provide an interactive and intuitive view of business performance.
